# Лабораторна робота 

## Предметна область

Керування складськими запасами та резервуванням товарів
для потреб ремонтних підрозділів.

## Обмежений контекст

Резервування товарів.

## Опис реалізації

У межах контексту реалізовано модель заявки на резервування
товарів для ремонтних підрозділів.

Модель отримує відомості про доступну кількість товару
та приймає рішення щодо заявки.

Якщо доступна кількість не менша за запитану,
заявка отримує статус Reserved і створюється запис резервування.

Якщо доступної кількості недостатньо,
заявка отримує статус Rejected із зазначенням причини відмови.

## Технології

- C++17
- CMake
- Visual Studio Code

- src/Model — предметна модель;
- tests — автоматизовані тести;
- CMakeLists.txt — конфігурація збірки.
